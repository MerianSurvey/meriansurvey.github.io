Data

Data releases and software

Merian provides seven-band photometry, HSC grizy plus N540 and N708, for sources across the survey footprint. The software written to plan, reduce and analyze the survey is public.

Data Release 1

DR1

The first data release is described in Danieli et al. (2024). It is built from observations taken between March 2021 and March 2022.

Instructions for accessing DR1 images and catalogs will be posted here.
Full color
320 deg² observed in both N540 and N708
Full depth
234 deg² at full depth in both filters
Bands
N540, N708 and HSC-SSP g, r, i, z, y
Photometry
Aperture-matched GAaP photometry for accurate colors
Pipeline
LSST Science Pipelines, on the HSC-SSP pixel grid
Schema
Catalog schema browser

Looking ahead

The final release

The final data release will cover the entire survey area, about 733 deg² in both filters and about 584 deg² at full depth, processed with a more recent version of the LSST Science Pipelines.

Software

Open-source tools

All Merian code lives in the MerianSurvey organization on GitHub.

  • caterpillar

    Image reduction and analysis pipeline for the Merian medium-band DECam survey.

  • lambo

    Model dwarf galaxies in HSC and Merian data with lambo, a sporty Tractor.

  • carpenter

    Handy tools for Merian data.

  • maria

    Basic tools for reading and using Merian science catalogs.

  • skipper

    Observing strategy, planning and observing scripts.

  • merian_schemas

    Catalog schemas, with an online schema browser.

  • notebooks

    Example notebooks for Merian data access with the Rubin Science Pipelines.

  • wasp

    Data reduction support.

Acknowledging Merian

How to cite

If you use Merian data, please cite the survey overview, Danieli et al. (2024). If your work relies on the filter design or the lensing forecast, please also cite Luo et al. (2024).
